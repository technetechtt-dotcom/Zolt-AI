# Operator guide

Zolt Console (`pnpm dev:console`) is advisory-only.

1. Sign in with a tenant user.
2. Use Command Centre for open recommendations and system health.
3. Acknowledge, approve or reject recommendations with a comment. Approval does not actuate equipment.
4. Treat `simulated: true` telemetry as test data, never as live plant state.
5. Use Copilot for explanations. It cannot issue plant commands.
